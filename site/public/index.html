A deterministic code map for AI coding agents

$ npm install -g @getdomovoi/osnova

основа: a foundation, and the warp a weave is built on

  1. Osnova is a Slavic word. It means base or foundation, and on a loom, the warp: the threads held taut so the cloth can be woven on them.
  2. Osnova reads your repository. Its own source at 0.11.0 is 397 files, 7,069 symbols and 31,453 edges.
  3. With tree-sitter, each file becomes a syntax tree, and declarations and calls become symbols and edges.
  4. It builds a symbol and call graph. The function refreshWorkspace calls 11 named functions, each tied to the line that calls it.
  5. Your agent asks who calls refreshWorkspace, through the osnova_warp tool.
  6. It gets exact file and line back, with the evidence for each caller, and unresolved calls listed apart.
  7. Same commit, same answer: two fresh builds produce byte-identical index files and identical output.
  8. Install with npm install -g @getdomovoi/osnova.

Where it sits in one agent turn

Osnova answers twice. Before the edit, with the symbols, callers and tests the task touches. After it, with what the change reached.

  1. prompt

    The developer asks for a change in billing.

    human
  2. footing

    The agent asks osnova for the symbols, callers and tests that touch the task.

    osnova
  3. edit

    The agent edits with exact paths and line ranges instead of a guess.

    agent
  4. settle

    Osnova re-indexes the diff and returns what the change reached.

    osnova
  5. review

    The developer reads the impact list, not the whole diff.

    human

1. Check that `node --version` reports 22.13 or newer. If it does not, stop and tell me.
2. Run `npm install -g @getdomovoi/osnova`.
3. Run `osnova setup claude`. It prints the config diff and writes nothing. Show me the diff.
4. When I approve, run `osnova setup claude --apply`. It backs up every file it changes.
5. Run `osnova doctor` and tell me about any warning.
6. Tell me to restart Claude Code so the MCP server, hooks and skill load.

Or run it yourself

Remove it with osnova setup claude --uninstall --apply.

Ten tools, named for the ground under the code

Your agent calls them over MCP. You can type the same names on the command line: osnova warp and osnova_warp run the same query.

Find

ground
Keyword search. Ranked definitions with exact file and line.
thread
Text search. Regex or literal matches, grouped by the symbol they sit in.
outline
Signatures and line spans for one file.
groundwork
Repository map. Directory clusters, hubs and hotspots.

Trace

footing
Task context. Definitions, relationships and candidate tests around a question.
warp
Call graph. Callers and callees, direct or transitive, with the evidence for each edge.
tests
The test files that reach a symbol, or the symbols one test file reaches.

Check

settle
Change impact. The symbols a diff touches and everything indexed that depends on them.
plumb
Checks a claimed list of call sites. Which the index confirms, and which it left out.
unreferenced
Definitions with no indexed caller, with their leads. Candidates, never proof.

What osnova does not do

  • No type inference. Edges come from syntax: calls, imports, name references, written heritage and framework routes. Resolution is heuristic, and every edge says how it was resolved.
  • No semantic search. ground ranks definitions by their words. It is fast and explainable, and it will not match a paraphrase.
  • No proof of safety. An empty caller list means the index found no caller, not that none exists.
  • No cost claims. Agent trials so far show the same correctness with and without the graph on small tasks.

Osnova is the Slavic word for base or foundation. That is the job: give an agent solid ground to stand on before it edits code.
